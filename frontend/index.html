    Correlation Rules Matrix

    Every risk classification is derived from explicit, testable rules that connect independent evidence vectors.

    LIVE RULE ENGINE TESTERSIMULATION
    VERDICT: HIGH_RISK
    TRIGGERED: R1, R2, R4
    RULE R1HIGH

    APK Install Request + APK Present

    Message instructs APK install + User provides APK file

    Connects coercive text with static APK metadata and dangerous permissions.

    RULE R2IDENTITY

    Claimed Org vs URL Mismatch

    Message claims Organization X + URL domain ≠ X

    Classic phishing: established brand claimed, domain belongs to unrelated infrastructure.

    RULE R3PACKAGE

    Claimed Org vs APK Package Mismatch

    Message claims Organization X + APK package/cert ≠ X

    Flags rogue Android packages signed by unknown debug certificates.

    RULE R4SOCIAL ENG

    Credentials + Coercive Urgency

    OTP / PIN request + Account threat / deadline

    Artificially induced time pressure to bypass security procedures.

    RULE R5EXTERNAL

    URL Phishing Flag + Instruction

    urlscan / VT malicious + Message instructs link click

    External threat intel confirms active phishing signatures.

    RULE R6FP GUARD

    Isolated URL Signal Alone

    Subdomains / HTTP only, no supporting threat signals

    Structural signals alone do not warrant a malicious verdict.

    RULE R7HONEST

    Evidence Missing = Insufficient Evidence

    Absence of signals ≠ Guaranteed safety

    System issues "INSUFFICIENT_EVIDENCE", never a false "SAFE" badge.
